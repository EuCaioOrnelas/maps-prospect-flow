# maps-prospect-flow

Atue como um empresário e product builder SaaS com múltiplos milhões faturados, especialista em produtos de alto ROI, margens acima de 50% e experiência do usuário extremamente clara e intuitiva.

OBJETIVO DO PRODUTO

Crie um SaaS de prospecção de leads via Google Maps, simples, poderoso e altamente lucrativo, focado em gerar oportunidades comerciais de forma previsível para freelancers, vendedores, agências e empresas.

O sistema deve ser percebido como:

Profissional

Rápido

Confiável

Fácil de usar mesmo por usuários leigos

A proposta deve ser clara em menos de 5 segundos ao bater o olho na interface.

NOME DO PRODUTO

Crie um nome:

Curto

Dinâmico

Memorável

Com apelo comercial

Que remeta a prospecção, descoberta ou crescimento

Evitar nomes genéricos. O nome deve parecer um SaaS premium.

FUNCIONALIDADE PRINCIPAL

O sistema deve permitir que o usuário faça buscas estratégicas no Google Maps, utilizando a SERP API, para encontrar empresas e profissionais com base em:

Palavra-chave

Cidade ou região

API a ser utilizada:

SERP API – Google Maps
Chave da API:
86a2d96476dcae7a9f5d335a8c3ea9d856887717fd8b7e09cd9fba5e726f02cb

ENTREGA DOS RESULTADOS

Os resultados da pesquisa devem ser entregues em massa, através de:

Download automático de planilha (Excel ou Google Sheets)

Cada lead deve ocupar uma linha, com os dados organizados em colunas separadas, incluindo sempre que disponível:

Nome da empresa

Categoria

Endereço

Cidade

Telefone

Site

Avaliação

Quantidade de avaliações

Link do Google Maps

MODELO DE USUÁRIO E ACESSO

O usuário obrigatoriamente precisa criar uma conta (e-mail + senha)

Todo novo usuário recebe 10 buscas gratuitas por mês

Ao atingir o limite gratuito, o sistema deve:

Bloquear novas buscas

Exibir CTA claro para upgrade de plano

MODELO DE COBRANÇA (SaaS)

⚠️ Nunca usar o termo “pesquisas” visivelmente para o usuário
Sempre usar o conceito de “buscas estratégicas”

PLANOS:
🔹 Plano Start

R$ 69 / mês

Até 200 buscas estratégicas por mês

🔹 Plano Growth (PLANO PRINCIPAL – destaque visual)

R$ 197 / mês

Até 600 buscas estratégicas por mês

Deve ser visualmente destacado como “Mais Popular”

🔹 Plano Scale

R$ 397 / mês

Até 1.200 buscas estratégicas por mês

POSICIONAMENTO DE VALOR (OBRIGATÓRIO NO SITE)

Nunca comunicar como:

“200 pesquisas”

Sempre comunicar como:

“Até 200 buscas estratégicas por mês para encontrar novos clientes.”

A comunicação deve enfatizar:

Economia de horas manuais

Prospecção previsível

Uso profissional

Foco em geração de oportunidades

Que 1 único cliente fechado pode pagar o plano inteiro

REGRAS TÉCNICAS OBRIGATÓRIAS (PARA PROTEGER MARGEM)

Implemente obrigatoriamente:

Limite de resultados por busca

Máximo de 20 a 30 leads por busca

Rate limit por usuário

Limite de buscas por hora

Bloqueio de automações abusivas

Sem rollover de buscas não utilizadas

Monitoramento interno de consumo por usuário

Painel administrativo simples para:

Ver uso por usuário

Bloquear usuários abusivos

Ajustar limites se necessário

DESIGN E UX/UI

O site e o sistema devem ser:

Modernos

Minimalistas

Estilo SaaS premium

Visualmente claros

Extremamente didáticos

O usuário deve:

Bater o olho

Entender o que o sistema faz

Saber exatamente o próximo passo

Priorizar:

Dashboard simples

CTA claro

Feedback visual de uso (ex: buscas restantes no mês)

OBJETIVO FINAL DO PRODUTO

Criar um ativo SaaS escalável, com:

Margem bruta acima de 50%

Uso previsível

Baixo suporte

Alta percepção de valor

Monetização recorrente
